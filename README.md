Features Implemented
- Responsive Navbar, Carousel, Cards, Alerts, and Pagination using Bootstrap 5.3.3
- Live Slot Schedule & Per-Player Bill Splitter tables using `rowspan` and `colspan`
- Complete Turf Booking Form with validation, radio buttons, checkboxes, range slider, and file upload
- HTML5 semantic tags (`<header>`, `<section>`, `<article>`, `<figure>`, `<details>`, `<video>`, `<audio>`, `<iframe>`) and CSS `@keyframes` animation
